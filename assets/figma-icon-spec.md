# LinguaLeap - App Icon Design Specification

## Design Concept
The icon represents language learning through a combination of a speech bubble (communication) and a globe (languages of the world), with the letter "L" as the central element.

## Color Palette
- **Primary Gradient**: #6C63FF -> #8B85FF (Purple/Indigo)
- **Accent Gradient**: #4ECDC4 -> #58CC02 (Teal to Green)
- **Gold Stars**: #FFC800
- **Text/Elements**: White (#FFFFFF)

## Icon Structure
1. **Background**: Rounded square with purple gradient
2. **Speech Bubble**: White semi-transparent speech bubble (center)
3. **Letter "L"**: Bold stylized "L" in purple gradient inside the bubble
4. **Globe**: Small teal/green globe icon representing global languages
5. **Stars**: Gold decorative stars for gamification feel
6. **App Name**: "LinguaLeap" in bold white text at the bottom

## Figma Implementation Notes
- Canvas size: 1024x1024px
- Corner radius for background: 220px
- Use Auto Layout for responsive scaling
- Export at @1x, @2x, @3x for iOS
- Export as adaptive icon (foreground/background) for Android
